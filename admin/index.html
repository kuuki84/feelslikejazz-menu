홈페이지와 연결하기

고친 내용을 홈페이지에 올리려면 이 기기에서 한 번만 열쇠(GitHub 토큰)를 넣어 주세요. 열쇠는 이 기기 브라우저에만 저장되고, GitHub 말고 다른 곳으로는 보내지 않아요.

관리자 비밀번호

정해 두면 이 페이지를 열 때 비밀번호를 물어봐요.

비밀번호는 화면을 가리는 문이고, 실제로 홈페이지를 고칠 수 있는 권한은 위의 열쇠(토큰)예요. 열쇠가 없는 사람은 비밀번호를 알아도 저장할 수 없어요.

열쇠(토큰) 만드는 방법

  1. GitHub에 kuuki84 계정으로 로그인하고 토큰 만들기 화면을 열어요.
  2. Token name에 jazz-admin, Expiration은 원하는 기간(길게 잡아도 돼요).
  3. Repository access → Only select repositories → feelslikejazz-menu 하나만 고르기.
  4. Permissions → Repository permissions → Contents를 Read and write로.
  5. Generate token을 누르고, 나온 글자를 복사해서 위 칸에 붙여 넣고 「연결하기」.

이 열쇠로는 이 홈페이지 저장소의 파일만 고칠 수 있어요. 휴대폰을 잃어버리면 GitHub에서 그 토큰을 지우면 돼요.
